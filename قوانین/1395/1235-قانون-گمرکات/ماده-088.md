# مادۀ هشتاد وهشتم

ختم مراحل گمرکی دارندۀ اثرات اقتصادی

(١) مراحل گمرکی دارندۀ اثرات اقتصادی، زمانی خاتمه می یابد که موقف گمرکی جدید برای اموال تحت مرحله یا برای تولیدات جبیروی و یا پروسس شده چنین اموالی، تعیین گردد.

(٢) مامورین گمرک جهت تعیین موقف گمرکی جدید برای اموال که مراحل تعلیقی گمرکی آن طبق احکام این قانون انجام نیافته، تدابیر لازم را اتخاذ می نمایند.
