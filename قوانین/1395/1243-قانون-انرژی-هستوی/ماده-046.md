# مادۀ چهل وششم

اجازه نامۀ واردات مواد، تجهیزات وتکنالوژی هستوی

اجازه نامۀ واردات مواد، تجهیزات و تکنالوژی قابل استفاده درفعالیت های هستوی به دارند ۀ جوازنامه تحت شرایط ذیل اعطاء می گردد:

١- داشتن موافقت کتبی مبنی برتورید مواد،تجهیزات وتکنالوژی هستوی ازمرجع دریافت کننده.

٢- معرفی مرجع تعیین شده جهت دریافت مواد، تجهیزات یا تکنالوژی هستوی.

٣- ارایه سند کتبی مبنی برداشتن توانایی استفاده کننده نهایی جهت استفاده ازمواد، تجهیزات وتکنالوژی هستوی وداشتن منابع اداری وتخنیکی در زمینه.
