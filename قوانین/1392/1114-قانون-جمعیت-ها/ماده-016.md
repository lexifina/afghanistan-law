# مادۀ شانزدهم

فصل سوم امورمالی منابع تمویل جمعیت

(۱ ) جمعیت ازمنابع ذیل تمویل شده می تواند:

- حق الشمول.

- حق العضویت.

- فروش نشرات.

- اعانه وهدایا ی اشخاص داخلی وخارجی.

(۲ ) جمعیت ها می توانند جهت تحقق اهداف مندرج اساسنامه مربوط کمک، مسلسل نمبر(١١١٤) /۶ / های مالی وت ک نیکی مؤسسات وجمعیت های خارجی را به آگاهی وزارت عدلیه بدست آورند.

(۳ ) منابع تمویل وموارد مالی جمعیت علنی بوده ودارایی آن تنها درجهت تحقق اهداف آن به مصرف می رسد.
