# مادۀ بیست وسوم

مسلسل نمبر(١١١٤) /۶ / مراقبت ونظارت

(۱ ) ادارۀ انسجام، بررسی وثبت جمعیت ها واحزاب سیاسی مکلف است، از اجراآت جمعیت ها و مطابقت فعالیت آنها با اساسنامۀ مربوط و قوانین نافذ، نظارت به عمل آورد.

(۲ ) جمعیت ها مکلف اند درپایان هر سال مالی گزارش فعالیت ودارایی منقو ل وغیر منقول خویش را به ادارۀ انسجام بررسی وثبت جمعیت ها واحزاب سیاسی ارائه نمایند.
