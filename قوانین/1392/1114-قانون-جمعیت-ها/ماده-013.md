# مادۀ سیزدهم

مسلسل نمبر(١١١٤) /۶ / مرجع ثبت

(۱ ) جمعیت ها از طرف وزارت عدلیه ثبت می گردند.

(۲ ) طرز تأسیس و ثبت جمعیت ها در مقررۀ جداگانه تنطیم می گردد.

(۳ ) جوازنامۀ فعالیت جمعیت ها به مدت سه سال توسط وزارت عدلیه دربرابر ده هزارافغانی صادر می گردد وبعد از سه سال قابل تمدید است.

(۴ ) وزارت عدلیه مؤظف است شعبه صدوروتمدید جوازنامه ها را درمراکز ولایات ایجاد نماید.
