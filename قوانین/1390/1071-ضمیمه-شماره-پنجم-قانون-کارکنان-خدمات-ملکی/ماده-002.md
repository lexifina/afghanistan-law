# مادۀ دوم

شخص ى به حیث ولسوال در بست دوم خدمات ملکی مقرر شده می تواند که علاوه بر معیار های مندرج اجزای(٣ الی ٦ ) فقرۀ(٢ ) مادۀ هشتم این قانون واجد معیار های ذیل نیز باشد:

١- داشتن حد اقل سند تحصیلی بکلوریا.

٢- داشتن تجربۀ کاری( بکلوریا (٨) سال ،فوق بکلوریا(٦) سال ولسانس(٣ )سال.)

٣- اکمال سن(٣٠ ) سالگی.
