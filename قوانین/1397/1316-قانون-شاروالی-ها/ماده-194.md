# مادۀ یکصد و نود و چهارم

مسلسل نمبر (١٣١٦) استفاده از تسهیلات تفریحی و ورزشی

(۱) شاروالی میتواند، جهت استفاده از تسهیلات تفریحی و ورزشی، موارد ذیل را در لایحۀ مربوط تنظیم نماید:

١- اوقات باز و بسته شدن.

٢- اندازۀ فیس در بدل استفاده.

٣- طرز استفاده از تسهیلات تفریحی و ورزشی.

٤- سایر موارد به تشخیص شاروالی.

(٢) هرگاه شخص احکام لایحۀ مندرج فقرۀ (١) این ماده را نقض نماید، توسط مؤظف شاروالی احکام لایحۀ مربوط بالای وی تطبیق میگردد.
