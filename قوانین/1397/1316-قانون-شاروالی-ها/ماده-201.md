# مادۀ دوصد و یکم

استفاده ازحوض های آب بازی و حمام های عمومی

شاروالی می تواند، جهت استفاده از حوض های آب بازی و حمام های عمومی، موارد ذیل را در لایحۀ مربوط تنظیم نماید:

١- اوقات باز و بسته شدن.

٢- اندازۀ فیس در بدل استفاده.

٣- طرز استفاده از تسهیلات حوض های آب بازی و حمام های عمومی.

٤- سایر موارد به تشخیص شاروالی.
