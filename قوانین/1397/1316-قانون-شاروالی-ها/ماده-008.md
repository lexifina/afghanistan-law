# مادۀ هشتم

اجرای وظایف و اعمال صلاحیت ها توسط شاروالی ها

(١) شاروالی های درجه اول مکلف مسلسل نمبر (١٣١٦) اند، وظایف و صلاحیت های مندرج این قانون را اجراء یا اعمال نمایند، مگر اینکه در این قانون طور دیگری تصریح گردیده باشد.

(٢) شاروالی های درجه دوم مکلف اند، وظایف وصلاحیت های مندرج این قانون را به استثنای وظایف و صلاحیت های مندرج ضمیمۀ شماره (٢) این قانون اجراء یا اعمال نمایند.

(٣) شاروالی های درجه سوم مکلف اند، وظایف وصلاحیت های مندرج این قانون را به استثنای وظایف و صلاحیت های مندرج ضمیمۀ شماره (٣) این قانون اجراء یا اعمال نمایند.
