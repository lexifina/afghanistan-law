# مادۀ یکصد و هشتاد و یکم

استفاده از تشناب های عمومی

(۱) شاروالی میتواند، موارد ذیل را در لایحه مربوط، تنظیم نماید:

١- اوقات باز وبسته شدن تشناب های عمومی.

مسلسل نمبر (١٣١٦)

٢- اندازۀ فیس در بدل استفاده از تشناب های عمومی.

٣- طرز استفاده از تشناب های عمومی.

٤- سایر موارد به تشخیص شاروالی مربوط.

(٢) هرگاه شخص احکام لایحۀ مندرج فقرۀ (١) این ماده را نقض نماید، توسط مؤظف شاروالی احکام لایحۀ مربوط بالای وی تطبیق میگردد.
