# مادۀ چهل وهفتم

فصل پنجم ساختار و طرز ادارۀ بانک ساختار اداری بانک ها

(١) بانک دارای ساختار اداری ذیل می باشد:

١- مجمع عمومی سهمداران.

٢- هیئت نظار.

٣- هیئت عامل.

(۲) بانک مکلف است، قبل از انتصاب شخص به حیث عضو هیئت نظار یا هیئت عامل، موضوع رابا ارائه معلومات واسناد طبق حکم مندرج مادۀ دوازدهم این قانون حین درخواست جواز بانک داری پیشنهاد واجازۀ دافغانستان بانک را در زمینه اخذ نماید.
