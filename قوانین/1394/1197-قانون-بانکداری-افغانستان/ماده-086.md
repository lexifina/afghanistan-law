# مادۀ هشتاد وششم

ممنوعیت ایجاد روابط با بانک های مجازی (غیر حقیقی)

بانک داخلی یا نمایندگی بانک خارجی که درکشور فعالیت می کند، نمی تواند، فعالیت های ذیل را انجام دهد:

١- ایجاد رابطۀ تعاملی دو ج انبه با بانک مجازی (غیرحقیقی) یا اعطای اجازه به بانک مجازی جهت استفاده از حسابات بانک.

٢- تداوم رابطۀ تعاملی با بانک مجازی بعد از انفاذ این قانون.
