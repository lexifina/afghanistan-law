# مادۀ هجدهم

ختم اعتبار جواز بانکداری

جواز بانکداری دریکی ازحالات ذیل از اعتبار ساقط می گردد:

١- عدم اجرای فعالیت بانکداری در خلال مدت شش ماه از تاریخ صدور جواز بانکداری.

٢- ادغام بانک طبق احکام این قانون و ثبت بانک جدید در دفتر ثبت مرکزی بانک ها.

٣- تجدید ساختار یا تجزیه بانک طبق احکام این قانون.

٤- درخواست واگذاری داوطلبانه جواز بانکداری.

٥- انتصاب مدیر تصفیه برای بانک طبق احکام این قانون.
