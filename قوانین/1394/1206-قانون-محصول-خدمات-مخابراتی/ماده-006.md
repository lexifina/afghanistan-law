# مادۀ ششم

فصل دوم محصول خدمات مخابراتی وجمع آوری آن اندازۀ محصول خدمات مخابراتی

(١) محصول خدمات مخابراتی ده فیصد می باشد.

(٢) محصول مندرج فقرۀ ( ١) این ماده طور ذیل وضع می گردد:

١- حین اضافه نمودن کریدت در حساب مربوط سیستم مخابراتی.

٢-حین ارایه انوایس( صورت حساب ماهانه ) یا بل مصرفی به اساس میعاد توافق شده.

٣-حین استفاده از سرکت اجاره شده براساس قرارداد بین عرضه کننده و استفاده کننده.

(٣) محصول خدمات مخابراتی مندرج فقرۀ (١) این ماده با نظرداشت وضع مالی دولت تعدیل قانونی شده می تواند.
