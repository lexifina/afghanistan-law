# مادۀ پنجم

اشخاصتابع محصول خدمات مخابراتی

اشخاص ذیل، به شمول سکتور خصوصی تابع محصول خدمات مخابراتی می باشند:

١- استفاده کننده خدمات تیلفون ثابت، تیلفون سیار (موبایل) نسل دوم وسوم و سایر تکن الوژی های تیلفون سیار ( موبایل)، خدمات رومنگ بین المللی (Services Roaming International)،خدمات رومنگ بین المللی داخل کشور (Roaming Inbound International( وخدمات رومنگ بین المللی خارج کشور (Roaming Outbound International).

٢- استفاده کننده سرکت های اجاره شده در داخل (Inbound) و خارج (Outbound) کشور.
