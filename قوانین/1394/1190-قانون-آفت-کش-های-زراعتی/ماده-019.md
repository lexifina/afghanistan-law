# مادۀ نزدهم

استفاده از آفت کش های زراعتی درحالات اضطراری

ادارۀ حفاظت نباتات وقرنطین می تواند، بعداز تائید کمیتۀ آفت کش های زراعتی، برای دارندۀ اجازه نامه، اجازه استفاده از آفت کش های زراعتی ثبت ناشده را در حالات اضطراری یا شیوع آفات نباتی بانظرداشت شرایط ذیل اعطاء نماید:

١- درصورتی که آفت کش زراعتی ثبت شده شامل لست کافی نبوده یا به اندازه نباشد که جلو آفات زراعتی را که باعث حالت اضطرار گردیده است، بگیرد.

٢- اجازه استفاده برای مدت معین بوده وتوسط کمیتۀ آفت کش های زراعتی تعیین شده باشد.

٣- دارندۀ اجازه نامه و محموله آن مشخص گردیده باشد.
