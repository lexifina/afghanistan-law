# مادۀ دوم

اهداف

اهداف این قانون عبارت اند از:

١- فراهم نمودن زمینۀ استملاک عادلانۀ ملکیت های اشخاص.

٢- تنظیم روش های تثبیت ملکیت های تحت استملاک.

٣- فراهم نمودن زمینۀ تطبیق ماستر پلان های شهری وسایر پلان های پروژه های عام المنفعه.

٤- تعیین معیار های تثبیت تعویض عادلانۀ ملکیت های تحت استملاک.

٥- فراهم نمودن زمینۀ انت قال ملکیت های دولت جهت تطبیق پروژه های عام المنفعه.

٦- اسکان مجدد مالکین ملکیت های تحت استملاک در پروژه های بزرگ ملی.

٧- جبران خسارۀ مالک و سایر اشخاص متضرر از پروسۀ استملاک.

٨- افزایش تاثیرات مثبت استملاک بالای مردم.
