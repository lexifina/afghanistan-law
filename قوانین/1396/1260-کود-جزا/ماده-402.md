# مادۀ ٤٠٢

مصادره وجوه پرداخت شده در جرم سوء استفاده از نفوذ

(١) وجوهی که تحریک کننده جهت استفاده از نفوذ آنرا پیشکش یا پرداخت نموده، مصادره می گردد، مگر اینکه قبلاً به مقامات مسؤ ول اطلاع داده باشد.

(٢) هرگاه از اثر ارتکاب جرایم مندرج این فصل، منفعت مستقیم یا غیر مستقیم مادی یا معنوی حاصل گردیده باشد، منفعت مادی، مصادره و منفعت معنوی، باطل می گردد.
