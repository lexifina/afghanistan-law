# مادۀ دوم

اهداف

اهداف این قانون عبارتند از:

١- ایجاد سیستم اشاعه، ثبت و ارزیابی دارایی های مقامات عالی رتبه دولتی، مقامات دولتی وکارکنان دولتی.

٢- فراهم نمودن زمینه تشخیص سوء استفاده از صلاحیت وظیفوی، سوء استفاده از نفوذ و افزایش غیر قانونی دارایی های مقامات عالی رتبه دولتی، مقامات دولتی وکارکنان دولتی.

٣- جلوگیری از حیف ومیل دارایی های عامه.
