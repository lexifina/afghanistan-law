# مادۀ بیستم

ادامۀ استفاده قبلی اختراع یا اکتشاف

هرگاه اختراع یا اکتشاف قبل ازتاریخ ثبت، توسط شخص حقیقی یا حکمی درداخل افغانستان استفاده گردد، باوجود این که شخص دیگر آن را ثبت نموده باشد، می تواند آنرا استعمال نماید، مشروط بر اینکه:

١- استفاده از اختراع یا اکتشاف بر اساس حسن نیت بوده وقبل ازتاریخ ثبت و تق دم ح ق اخت راع شخص دو می باشد.

٢- از محدوده و اندازه استفاده قبلی افزایش به عمل نه آید.

۳- حق ادامه استفاده قبلی باشغل مرتبط به آن یکجا بشکل کلی یاقسمی منتقل گردد.
