# مادۀ سی وهشتم

طرزالعمل استفاده از رخصتی ها

(۱) رخصتی تفریحی افسران وساتنمنان مطابق طرزالعمل جداگانه طوری تنظیم میگردد که سطح احضارات وظیفوی قطعات وجزوتام های مربوط، حفظ گردد.

(۲) شرایط اعطای رخصتی مندرج مواد سی دوم وسی وسوم این قانون وطرزالعمل استفاده ازآن درحالت احضارات وظیفوی طبق طرزالعمل جداگانه تنظیم می گردد.
