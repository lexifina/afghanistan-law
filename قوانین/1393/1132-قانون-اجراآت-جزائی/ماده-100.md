# مادۀ صدم

مدت توقیف در جریان تحقیق

(١)ارنوال میتواند بعد از تسلیمی مظنون در صورت موجودیت دلایل مندرج فقرۀ(٣ ) مادۀ نود ونهم این ق انون امر توقیف او را در جرم جنحه برای مدت(٧ ) روز ودرجرم جنایت حسب احوال برای مدت(١٥ ) روز صادر نماید .

(٢ ) هرگاه شخص تحت توقیف یا وکیل مدافع ویا مساعد حقوقی وی علیه دوام توقیف اعتراض داشته ویا ارنوال تمدید توقیف را مطابق حکم فقرۀ(٣ ) این ماده تقاضا،نمایدارن وال باید شخص تحت توقیف را(٣ ) روز قبل از انتهای مدت تمدید توقیف به پیشگاه محکمه غرض اصدار قرار تمدید توقیف حاضر نماید .

متهم، وکیل مدافع یا مساعد حقوقی وی حین تصمیم گیری حق حضور و اعتراض را دارند.

(٣ ) هرگاه در جرم جنحه مدت(٧ ) روز ودر جرم جن ایت مدت(١٥ ) روز برای اکمال تحقیق و ترتیب صورت دعوی کافی نباشد، ارنوال می تواند با رعایت مراتب مندرج فقرۀ(٢ ) این ماده پیشنهاد تمدید توقیف متهم را حسب احوال طورذیل به محکمۀ ابتدائیۀ مربوط تقدیم نماید:

١- در جرم جنحه مدت الی(١٠ ) روز.

٢- درجرم جنایت مدت الی(٣٠ ) روز .

(٤ ) هرگاه ضرورت توقیف متهم قبل از تکمیل مدت توقیف بر طرف گردد، امر توقیف حسب احوال مانع رهائی او به قید کفالت بالمال یا بدون آن نمی شود .

(٥ ) هرگاه ارنوال در میعاد مندرج فقرۀ(٣ ) این ماده نه تواند، تحقیق را تکمیل وصورت دعوی را ارایه نماید وضرورت تمدید توقیف متهم مطابق احکام این قانون لازم باشد، محکمۀ ابتدائیه به پیشنهاد ارنوالی بعد از ارزیابی دلایل ارنوال و اظهارات متهم می تواند توقیف وی را در جرم جنحه الی مدت(١٠ ) روز ودرجرم جنایت الی مدت(٣٠ ) روز تمدید نماید .

متهم و وکیل مداف ع یا مساعد حقوقی او حین تصمیم گیری حق حضور واعتراض را دارند .

(٦ ) تمدید مدت توقیف متهم به هیچ ًوجه از طرف محکمۀ ابتدائیه مجموعا در جرم جنحه از(٢٠ ) روز ودر جرم جنایت از(٦٠ ) روز بیشتر صادر شده نمی تواند.
