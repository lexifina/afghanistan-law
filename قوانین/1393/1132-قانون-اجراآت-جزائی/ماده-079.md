# مادۀ هفتاد ونهم

عفو عمومی و اثرات آن

(١ ) عفو عمومی توسط قانون صورت می گیرد و به اثرآن دعوای جزائی منقضی می گردد.

(٢ ) عفو عمومی تمام جزا های اصلی، تبعی، تک میلی و تدابیر امنیتی را ساقط می نماید.

(٣ ) هرگاه قانون عفوعمومی درمورد یک جزاء ازجزاهای محکوم بها صادرشده باشد، در حکم عفوخصوصی شمرده شده، احکام عفوخصوصی برآن تطبیق می گردد.

(٤ ) عفوعمومی موجب اخلال حقوق غیرنمی گردد.
