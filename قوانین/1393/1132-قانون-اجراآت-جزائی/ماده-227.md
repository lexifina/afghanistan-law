# مادۀ دوصد وبیست وهفتم

فصل نهم غور و مباحثه قضائی مباحثه قضائی

(١ ) محکمه بعد از است ماع دعوای ارنوال، دفع متهم و مدافعات آنها،استماع شهود واظهارات اهل خبره، غور و مباحثۀ قضائی را آغاز می نماید.

(٢ ) غور ومباحثۀ قضائی شامل بررسی ارنوال، دفع محتویات دعوای متهم، مباحثات طرفین وسایر شاملین دعوی، دلایل جمع آوری شده و سایر مندرجات و اورا ق تحقیق می باشد.
