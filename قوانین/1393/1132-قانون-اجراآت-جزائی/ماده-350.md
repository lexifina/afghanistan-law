# مادۀ سه صد وپنجاهم

موانع تخفیف وعفو

(١ ) مجازات محکومین جرایم ذیل شامل تخفی ف و عفو نمی گردد:

١-جرایم حدود.

٢-قصاص.

٣- دیت، مگر اینکه مقتول وارث نداشته باشد.

(٢ ) مجازات حبس محکومین جرایم ذیل عفو شده نمی تواند:

١-قتل عمد.

٢- اختطاف به مقصد بدست آوردن مال یا منفعت.

٣-گروگان گیری.

٤-فساد اداری.

٥-قاچاق مواد مخدر.

٦-مجرمین متک رر.

٧- سایر جرایم به تشخیص رئیس جمهور.

(٣) مجازات حبس محکومین جرایم مندرج اجزای(٢و١ ) فقرۀ(٢ ) این ماده در صورتی تخفیف شده می تواند که در جرم قتل ورثۀ مقتول ابراء و در جرم اختطاف، مال یا منفعت بدست آمده را به مجنی علیه رد نموده باشد.

(٤ )تخفیف مجازات محکومین جرایم مندرج فقرۀ(٢ ) با رعایت حکم فقرۀ(٣ ) این ماده بیشتر از(٣ بر ٤ ) حصۀ آن جواز ندارد.
