# مادۀ سه صد وبیست وششم

نحوۀ اجرای خدمت

(١ ) محکوم تعهد نماید که کار سپرده شده را در وقت معین آن به حسن صورت با دریافت(٣٠ ) فیصد اصل مزد مربوط انجام دهد و شرایط مندرج فقرۀ(٤ ) مادۀ سه صد وبیست وپنجم این قانون را رعای ت می نماید.

(٢ ) هرگاه مرجع انجام خدمت، مؤسسات یاتشبثات خصوصی باشد، مکلف است(٧٠ ) فیصد باقیماندۀ مزد روزمرۀ محکوم را بحساب دولت انتقال دهد.

(٣ ) سایر امورمربوط به انجام خدمات اجتماعی در مقررۀ جداگانه تنظیم می گردد.
