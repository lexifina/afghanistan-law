# مادۀ دوصد وبیست وپنجم

اخلال نظم جلسه توسط کارکنان محکمه

(١ ) هرگاه اخلال کنندۀ نظم جلسۀ قضائی از جملۀ کارکنان محکمه باشد، رئیس جلسۀ قضائی می تواند مطابق احکام قانون وی را تأدیب نماید.

(٢ ) هرگاه سایر اشخاص شامل جلسه، نظم جلسه را اخلال نموده یا اوامر رئیس جلسۀ قضائی را اطاعت ننمایند، رئیس می تواند اخلال کننده را از جلسۀ قضائی اخراج و به جزای نقدی الی (٥٠٠٠ ) هزار افغانی محکوم نماید.
