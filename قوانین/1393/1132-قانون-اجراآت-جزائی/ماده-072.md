# مادۀ هفتاد ودوم

مرور زمان دعوای جزائی

(١ ) دعوای جزائی بعد از گذشت مواعید ذیل ساقط می گردد:

١- در صورت ارتکاب جرم جنایت (١٠ )سال.

٢- در صورت ارتکاب جرم جنحه(٣ ) سال.

٣- در صورت ارتکاب جرم قباحت (١ )سال .

(٢ ) جرایم مندرج اساسنامۀ محکمۀ جزائی بین المللی و سند نهائی کنفرانس دپيلو ماتیک روم از حکم مندرج فقرۀ(١ ) این ماده مستثنی می باشد.

(٣ ) هیچ سبب نمی تواند مدتی را که برای سقوط دعوای جزائی تعیین گردیده است، اخلال نماید، مگر این که قانون صراحتاً به آن حکم نموده باشد.
