# مادۀ ششم

مکلفیت های کارکن

(١) کارکن دارای مکلفیت های ذیل می باشد:

١- استفاده مناسب از البسۀ عادی کار و وسایل تحفظی.

٢- رعایت قواعد تخنیک ایمینی و حفظ الصحۀ محیط کار.

٣- عدم استفاده از وسایل تحفظی، خارج از ساحه کار.

(٢) هر گاه کارکن از عدم رعایت حکم مندرج فقرۀ ( ١) این ماده متضرر گردد، خسارات ناشی از آن متوجه وی می باشد.
