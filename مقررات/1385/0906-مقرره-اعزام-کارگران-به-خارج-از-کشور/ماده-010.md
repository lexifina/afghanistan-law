# مادۀ دهم

اختلافات احتمالی

(۱ ) درصورت بروز اختلاف ناشی از کار میان کارگر وکار فرما، موضوع به نمایندگی سیاسی افغانستان اطلاع وباشرکت اتحادیه کارگری مرجع استخدام کننده، اختلاف ابتداءً ازطریق مفاهمه حل وفصل می گردد .

(۲ ) درصورتیکه اختلاف ازطریق مفاهمه حل شده نتواند بانظرداشت قوانین هردو کشور، توافقنامه یا قرارداد، قوانین مرتبط به کار سازمان بین المللی کار (ILO ) وسازمان بین المللی (IOM ) حل وفصل میگردد .
