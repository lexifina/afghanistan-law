# مادۀ شانزدهم

تعیین کاهش توانایی کار

درجه کاهش توانایی کارکارکن متضرر، حسب احوال توسط کمیسیون صحی مرکزی یا ولایتی تثبیت معلولیت شفاخانه های مربوط، بارعایت احکام اسناد تقنینی، بانظرداشت درجۀ خساره وارده طبق معیار های معینۀ صحی و فیصدی معلولیت (کلی یا قسمی) تعی ین گردیده و درج فورم های شماره (٣ و ۴) منضمۀ این مقرره می گردد.
