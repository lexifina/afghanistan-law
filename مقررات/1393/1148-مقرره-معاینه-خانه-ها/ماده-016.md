# مادۀ شانزدهم

فصل چهارم احکام متفرقه تأدیب

(١ ) کارکن طبی در صورت تخلف از احکام این مقرره حسب ذیل تأدیب می گردد:

١- بار اول، توصی ۀ کتبی.

٢- باردوم، اخطارکتبی.

٣- بارس وم، ج ریمۀ نق دی حسب احوال از پنج هزار(٥٠٠٠ ) الی ده هزار(١٠٠٠٠) افغانی.

٤- بار چهار م مسدود شدن معاینه خانه حسب احوال از یک الی سه ماه.

(٢ )درصورت اضافه ستانی فیس، علا وه بر استرداد مبلغ اضافه ستانی شده کارکن طبی مطابق اجزای( و ٣ ٤) فقرۀ (١ ) این ماده م ورد تأدیب نیز قرار می گیرد.

(٣ )جریمۀ نقدی مندرج جز ء( ٣ ) فقرۀ (١ ) این ماده به حساب واردات دولت تحویل بانک می گردد.
