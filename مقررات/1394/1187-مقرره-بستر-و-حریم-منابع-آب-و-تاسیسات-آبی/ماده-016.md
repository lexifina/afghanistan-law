# مادۀ شانزدهم

فعالیت های ممنوعه در زون ( ٢) چاه های عمیق

فعالیت های ذیل درزون(٢) چاه های عمیق آب ممنوع می باشد:

١- فعالیت های مندرج مادۀ پانزدهم این مقرره.

٢- اعمار وتوسعه ساختمانها برای مقاصد تجارتی و زراعتی .

٣- اعمارسرک مگر اینکه به منظور بهبود و تسهیل در حفاظت آبهای زیر زمینی باشد.

٤- پخش مواد آلوده کنندۀ آب.

٥- استفاده زمین بحیث چراگاه.

٦- ذخیرهکودکیمیاوی وآفت کش های زراعتی که منابع آب را آلوده سازد.

٧- پخش فاضلاب.

٨- احداث وتوسعه زابر.

٩- جاری ساختن آب های سطحی که فاضلاب را انتقال دهد.

١٠- استفاده ازکیبل های برق و ترانسفارمر دارای مایعات سرد کننده.

١١- انفجار مواد منفجره.

١٢- قبرستان.

١٣- سایر موارد مشابه به تشخیص وزارت انرژی و آب و سایر ادارات ذیربط.
