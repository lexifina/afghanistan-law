# مادۀ دوازدهم

حق الزحمۀ تدریسی

(١ ) حق الزحمۀ تدریس درمکا تب تعلیمات عمومی وسو اد آموزی با نظرداشت درجۀ تحصیل، حسب ذیل تعیین می گردد:

١- برای دارندۀ سند تحصیلی بکلوریا، فی ساعت درسی مبلغ شصت(٦٠ ) افغانی.

٢- برای دارندۀ سند تحصیلی فوق بکلوریا، فی ساعت درسی مبلغ هفتاد(٧٠ ) افغانی.

٣- برای دارندۀ سند تحصیلی لسان س ، فی ساعت درسی مبلغ هشتاد(٨٠ ) افغانی.

٤- برای دارندۀ سند تحصیلی ماستری ، فی ساعت درسی مبلغ یک صد(١٠٠ ) افغانی.

(٢ ) حق الزحمۀ تدریس در دارالمعلمین های تربیۀ معلم، انستیتوت ها ، مکاتب تخنیکی– مسلکی، حرفوی وهنری ، دار العلوم ها ومدارس تعلیمات اسلام ی با نظ رداشت د رجۀ تحصیل حسب ذیل تعیین می گردد:

١- برای دارندۀ سند تحصیلی فوق بکلوریا ، فی ساعت درسی مبلغ هشتاد(٨٠ ) افغانی

٢- برای دارندۀ سند تحصیلی لسانس ، فی ساعت درسی مبلغ یک صد(١٠٠ )افغانی.

٣- برای دارندۀ سند تحصیلی ماستری فی ساعت درسی مبلغ یکصد وبیست(١٢٠ )افغ انی.

٤- برای دارندۀ سند تحصیلی دوکتورا فی ساعت درسی مبلغ یکصد وپنجاه(١٥٠ ) افغانی.

(٣ ) حق الزحمۀ تدریس مندرج فقرۀ(٢و١ ) این ماده از بودج ۀ وزارت معارف پرداخته می شود.

(٤ ) مجموع انداز ۀ حق الزحمۀ مندرج فقره های(٢و١ ) این ماده از مجموع معاش ماهانۀ منسوب ین مؤسسات تعلیمی وزارت معارف بیشتر بوده نمی تواند.
