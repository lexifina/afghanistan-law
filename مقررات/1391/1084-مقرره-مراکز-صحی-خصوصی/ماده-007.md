# ماد ۀ هفتم

تصنیف شفاخانه ها

(١ ) شفاخانه های خصوصی از لحاظ عرضۀ خدمات بدو بخش عمومی و اختصاصی تصنیف می گرد ند.

(٢ ) شفاخانۀ عمومی :

شفاخانۀ است که خدمات کلینیکی را به طور داخل بستر و سراپا وخدمات حمایتی و تقویتی مورد نیاز را عرضه مى نماید .

(٣ ) شفاخانۀ اختصاصی :

شفاخانۀ است که یک یا دو نوع خدمات اختصاصی مرتبط را عرضه می نماید .
