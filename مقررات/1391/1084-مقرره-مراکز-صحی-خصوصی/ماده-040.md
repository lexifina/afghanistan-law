# مادۀ چهلم

فصل هفتم احکام متفرقه حق الاجرت(فيس)

(١ )مرکز صحی خصوصی دربرابر عرضۀ خدمات ذیل حق الاجرت (فیس ) اخذ می نماید :

١-خدمات کلینیکی .

٢- خدمات حمایتی( پاراکلینیکی و تشخیصی .)

٣-خدمات تقویتی.

(٢ ) اندازۀ حق الاجرت(فیس ) مندرج فقرۀ(١ ) این مادۀ از طرف کمیسیون مندرج مادۀ بیست وچهارم این مقرره تعیین می گردد .

(٣ ) رئيس يا مسئول مرکز صحی خصوصی مکلف است، جهت اطمینان مریض سند رسید حق الاجرت(فیس ) را در برابر عرضۀ خدمات به مریض تسلیم دهد.
